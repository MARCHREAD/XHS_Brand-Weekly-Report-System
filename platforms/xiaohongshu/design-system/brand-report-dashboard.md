# 真实品牌周报界面规范

以已有 `web/brand-report/demo.html` 为视觉参考，保留深蓝固定侧栏、浅灰背景、白色面板与双栏内容结构。真实数据页面为 `dashboard.html`，使用 HTML、CSS、JavaScript，不新增前端依赖或远程图表 CDN。

品牌主色为 `#173b70`，侧栏 `#102a4c`，数据蓝 `#2d6cdf`，互动琥珀色 `#c48019`，正向绿 `#25805b`，负向红 `#c5485a`。辅助文字使用可读的蓝灰色，并保留键盘焦点和减少动画偏好。

首屏为品牌与日期选择、分析范围、数据覆盖提示、四张 KPI 卡、趋势与观察。下方依次呈现话题、竞品、情绪、行动、采集、模型与快照。模型原理、标注和采集参数放在下方或独立管理页面。

趋势使用真实发布日期与采集时累计互动。声量对应左轴，累计互动对应右轴，SVG 文字显式取消描边。缺失指标断线或显示缺失，不补随机数据。情绪环图只包含已判定三类，待复核另列，正向率以有效分类数为分母。竞品份额标为已采样本份额。

品牌、周次与跨期范围可交互切换；话题和评论支持原文下钻；导出使用当前分析范围；行动勾选状态保存在本地浏览器；历史快照冻结模型和数据口径，实时采集进度另作标识。

验证尺寸为 1440、1024、768、375 像素。小屏侧栏缩窄，最小屏隐藏，图表与面板依次堆叠；表格只在容器内滚动。外部文本统一转义，按钮与对话框具有可识别标签。
